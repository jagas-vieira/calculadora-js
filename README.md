# calculadora-js

Sobre o projeto

A calculadora-js é um projeto desenvolvido para praticar os fundamentos do desenvolvimento Frontend, utilizando HTML, CSS e JavaScript.

A aplicação permite realizar operações matemáticas básicas através de uma interface simples e intuitiva.

Funcionalidades

- Adição.
- Subtração.
- Multiplicação.
- Divisão.
- Limpeza dos valores introduzidos.
- Apresentação dos resultados no ecrã.

Tecnologias utilizadas

- HTML5 — estrutura da aplicação.
- CSS3 — estilos e interface visual.
- JavaScript — lógica e operações matemáticas.

Objetivo

Consolidar os conhecimentos de HTML, CSS e JavaScript através de um projeto prático.

Como executar

1. Clona ou descarrega este repositório.
2. Abre a pasta do projeto.
3. Abre o ficheiro "index.html" no navegador.

Estado do projeto
